# Portfolio Documentation

Personal portfolio website for Kuldeep Vansadia.

**Live:** [kuldeepvansadia.com](https://kuldeepvansadia.com/)

## Stack

| Layer | Tech |
|-------|------|
| Framework | React 18 + TypeScript (strict) |
| Styling | Tailwind CSS 3 |
| Routing | React Router 6 |
| Animation | Framer Motion |
| Email | EmailJS |
| Backend | Firebase (configured, unused) |

## Design

**Web Brutalist + Functional**
- Monochrome (black/white) + red accent
- IBM Plex Mono typography
- No border radius, sharp edges
- High contrast, minimal decoration

Design can be changed later by modifying `tailwind.config.js` and `index.css`.
